# M3 Review — Full-ABI Layer

## Scope

Raw loader behavior, pointer and ownership documentation, declaration looseness, package exports, and CI test ordering.

## Confirmed findings

- Raw tests could be skipped if the full-ABI build did not precede them in CI.
- The destruction example needed the correct pointer-to-pointer calling convention.
- Consumers needed an explicit package path for the full-ABI wasm.
- Types that pointed into source files required a real downstream consumer gate.

## Disposition

- CI now builds the full ABI before raw tests.
- The destruction path and documentation use staged pointer storage correctly.
- Package exports include full-ABI JavaScript, wasm, and declarations.
- M4 added distributable declaration emission, strict downstream compilation, package analysis, and runtime consumption.
- The package intentionally includes the full ABI; curated decode absence applies only to the default artifact.

## Evidence

CI runs 33913374420 and 33914534570 passed after the fix round.

## Decision

Pass. All blockers were fixed and transferred conditions were later closed by M4.
